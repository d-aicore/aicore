## 9. This machine's traps (they cost time today)

- **`core.autocrlf` must be `false`** in any AICore-C clone: `.gitattributes` declares `* -text` because
  `manifest.json` hashes bytes. With autocrlf=true, 19 files show as "modified" by pure CRLF and the version gets
  `.modified`, which breaks the version gate. Prove it is noise before restoring: `git diff --ignore-cr-at-eol --stat`
  (must be empty).
- `cmake`/`ninja` **are not on Git Bash's PATH** — they come from VS (`...CommonExtensions\Microsoft\CMake\...`); that
  is why `build-s0.cmd`/`build-s5.cmd` inject them.
- **One clone per actor**: sharing `main` with workers in the same checkout already caused a HEAD race.
- Qoder's workspace registry only has `D:\AIcore-new` and `D:\DMO-AUDITS`; dispatching to a new clone uses the
  registered workspace + absolute paths in the instruction, not an invented `workspaceId`.
- Quotes in shell prompts: in Qoder files the word "plan" alone can be read as a slash command — describe the work in
  prose.
- Python heredocs in Git Bash turned `\n`, `\v`, `\\` into real characters several times: write helper scripts to a
  file, or build the strings with `chr(92)`.
- `%APPDATA%` writes from this agent's sandbox go to a package cache: the owner's apps do not see them.
